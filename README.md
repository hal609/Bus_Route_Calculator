# Bus + Walking Route Calculator

Code to create a graph of bus stops, bus routes between them, OA centroids, schools and the walking times between each. It then uses Dijkstra's to find optimal multi-model routes.

Walking times are computed using OSRM (https://github.com/Project-OSRM/osrm-backend) and bus data is gather from the BODS archive from The National Data Library: https://data.datalibrary.uk/transport/BODS-ARCHIVE/
